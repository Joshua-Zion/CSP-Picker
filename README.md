# CSP Picker 灵动拾色

**纯软件实现 TourBox「灵动拾色器」对 CLIP STUDIO PAINT 的核心能力**：
屏幕取色 / 手动调色 → 直接写入 CSP 的绘画颜色（主色 / 副色 / 透明色）。
不依赖任何硬件，单机可用。

## 原理

复用了 TourBox Console 内部使用的 CSP「连接智能手机」Companion 本地通道：
CSP 开启「连接智能手机」后会在 `127.0.0.1:<port>` 开放 TCP 服务，
本工具自动识别屏幕上的 QR 码、完成认证后即可发送 `SetCurrentColor` 命令，
**无需注入、无需模拟点击 CSP 界面**，颜色直达绘画色板。

## 使用方法

1. **启动**：`npm start`（首次需先 `npm install`）
2. 在 CSP 中点击命令栏 **「连接智能手机」**，弹出 QR 码窗口
3. 工具会**每 10 秒自动扫描屏幕上的 QR 码并自动配对连接**——通常什么都不用点；
   也可以在 ⚙ 设置里点「扫码配对」立即连接（识别不到时降级为手动框选）
4. 之后随时：
   - 按 **Alt+C** 屏幕取色，或在色轮 / 滑条上拖动调色
   - 开启「自动注入」后颜色变化**实时写入 CSP**；在 CSP 里改色，工具也会自动跟随
   - 前景 / 背景 / 透明三个颜色槽独立记忆，点击槽位卡片切换
   - 「固定到屏幕」让窗口始终置顶

## 功能

- **三色槽独立记忆**：前景色 / 背景色 / 透明色各自保存颜色，互不干扰，切换槽位即切换注入目标
- **双色轮**（还原 TourBox 灵动拾色器几何）：HSL 色轮（色相环 + 白/纯色/黑三角）与 HSV 色轮（色相环 + 内接 SV 方块），右下角单图标切换
- **五模式滑条**：HSV / HSL / RGB / CMYK / Lab，与色轮实时联动；拖动会话锚定（其余分量按下时固定，不乱跳）
- **上一次颜色**：色轮左下角显示当前色 + 上一次色（一体圆角矩形）；「上一次」在调完（松手）后才记录，不随拖动刷新
- **屏幕取色**：`Alt+C` 呼出放大镜取色（不透明覆盖层，兼容软件渲染环境）
- **双向同步**：本工具改色 → 节流 40ms 自动注入 CSP；CSP 改色 → 100ms 心跳同步回来（自动跟随 CSP 当前编辑的槽位）
- **托盘常驻**：关闭窗口 = 隐藏到托盘，与 CSP 的连接不断开；单实例运行
- **自动配对/断线恢复**：QR 监视永续（每 10 秒），断线后旧配对重连限 3 次，检测到新 QR 自动重新配对
- **固定到屏幕**：窗口置顶开关，画图时悬浮在 CSP 旁

## 注意事项

- CSP 侧需保持「连接智能手机」开启。CSP 的配对密钥是**一次性**的——每次成功配对后旧密钥即作废，
  因此关闭 CSP 的 QR 窗口再重新打开（显示新二维码）后，本工具会自动扫码重新连接，无需手动操作
- 需要 CSP 2.0 及以上版本（Companion 模式自 2.0 起提供）
- 若 Alt+C 与其他软件冲突，可修改 `main.js` 中的快捷键注册
- 该通道为 CSP 面向「伙伴设备」的私有协议（TourBox 亦使用此通道），
  仅建议个人使用；CSP 大版本更新后若协议变化可能需要适配

## 文件结构

```
CSP-Picker/
├── main.js           # 主进程：窗口、截屏、QR 自动扫描、托盘、断线恢复
├── csp-client.js     # CSP Companion TCP 协议客户端（可独立测试）
├── preload.js        # 上下文桥
├── index.html        # 主界面（Apple HIG 风格，自绘标题栏）
├── renderer.js       # 主界面逻辑（三色槽 / 双色轮 / 五模式滑条 / 双向同步）
├── overlay.html/js   # 屏幕取色覆盖层（放大镜 + 十字线）
└── qr-overlay.html/js # QR 码手动框选覆盖层（自动识别失败时的降级方案）
```
